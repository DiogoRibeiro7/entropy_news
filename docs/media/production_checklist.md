# Production Checklist

Use this checklist before publishing multimedia assets alongside Release 1.0
documentation.

1. **Pre-production**
   - [ ] Storyboard approved (:doc:`storyboard`).
   - [ ] Script reviewed by domain experts.
   - [ ] Demos rehearsed using the environments described in
     :doc:`../tutorials/dashboard_story` and :doc:`../tutorials/inference_delivery`.
2. **Recording**
   - [ ] Capture 1080p footage with clear audio.
   - [ ] Record backup audio and screen captures.
   - [ ] Note timestamps for key segments to simplify editing.
3. **Post-production**
   - [ ] Edit transitions and add callouts referencing tutorials or API pages.
   - [ ] Generate captions and transcripts following :doc:`accessibility`.
   - [ ] Export MP4 and WebM variants for compatibility.
4. **Publication**
   - [ ] Upload assets to the shared media repository with semantic filenames.
   - [ ] Embed videos using the HTML snippet in :doc:`storyboard`.
   - [ ] Announce availability in release notes and update :doc:`../index`.
